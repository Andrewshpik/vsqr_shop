# VSQR — магазин 3D-печатных изделий

Витрина и приём заявок для мастерской 3D-печати. Сделано на Next.js 14
(App Router) + Tailwind. Корзина хранится в `localStorage`, оформление —
форма-заявка без платёжного шлюза.

## Что внутри

- Главная с подборкой хитов и схемой работы
- Каталог с фильтрами по категории, поиском и сортировкой
- Карточка товара со спецификацией и выбором цвета
- Корзина с количеством и расчётом доставки
- Чекаут: контакты, способ доставки и оплаты, комментарий, флаг «у меня свой файл»

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

## Сборка

```bash
npm run build
npm start
```

## Где править контент

- Товары: `lib/products.ts`
- Категории: `lib/types.ts` (`CATEGORY_LABELS`)
- Контакты / футер: `components/Footer.tsx`
- О мастерской: `app/about/page.tsx`
- Стоимость доставки: константа `SHIPPING` в `app/cart/page.tsx` и
  `app/checkout/page.tsx`

## Деплой на shop.vsqr.ru через Vercel

Лендинг подключается как поддомен — основной vsqr.ru не трогаем.

### 1. Загрузить код на GitHub

В корне репозитория (уже инициализирован):

```bash
# Создать пустой репозиторий на github.com → скопировать его URL
git remote add origin https://github.com/<юзер>/vsqr-shop.git
git push -u origin main
```

### 2. Подключить к Vercel

1. Зайти на https://vercel.com → войти через GitHub.
2. **Add New → Project** → выбрать репозиторий `vsqr-shop`.
3. Framework определится автоматически (Next.js). Все настройки можно
   оставить по умолчанию → **Deploy**.
4. Через ~1 минуту получите временный адрес вида
   `vsqr-shop-xxx.vercel.app` — проверьте, что сайт открывается.

### 3. Прикрепить домен shop.vsqr.ru в Vercel

В проекте Vercel: **Settings → Domains → Add** → ввести
`shop.vsqr.ru` → **Add**.

Vercel покажет, какую DNS-запись нужно добавить. Обычно это
**CNAME** на `cname.vercel-dns.com`.

### 4. Добавить DNS-запись в Reg.ru

1. Войти в [lk.reg.ru](https://www.reg.ru/user/) под учётной записью папы.
2. **Мои домены и услуги → vsqr.ru → Управление DNS-серверами и зоной**.
3. **Добавить запись:**
   - Тип: `CNAME`
   - Имя (поддомен): `shop`
   - Значение: `cname.vercel-dns.com.` (точка в конце — обязательно)
   - TTL: оставить по умолчанию
4. Сохранить.

DNS обновится за 5–30 минут (иногда до часа). Vercel сам выдаст
SSL-сертификат Let's Encrypt автоматически.

### 5. Проверить

Через ~30 минут открыть `https://shop.vsqr.ru` — должен открыться
лендинг с замочком HTTPS. В Vercel → Domains у `shop.vsqr.ru`
будет зелёная галочка.

### Обновления сайта

Любой `git push` в `main` автоматически пересобирает и выкатывает
новую версию на shop.vsqr.ru за минуту.
