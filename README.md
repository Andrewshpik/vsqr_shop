# VSQR — магазин 3D-печатных изделий

Витрина и приём заявок для мастерской 3D-печати. Сделано на Next.js 14
(App Router) + Tailwind. Корзина хранится в `localStorage`, оформление —
форма-заявка без платёжного шлюза.

## Что внутри

- Главная с подборкой хитов и схемой работы
- Каталог с фильтрами по категории, поиском и сортировкой
- Карточка товара со спецификацией и выбором цвета
- Корзина с количеством и расчётом доставки
- Чекаут: контакты, способ доставки и оплаты, комментарий, флаг «у меня свой файл»

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

## Сборка

```bash
npm run build
npm start
```

## Где править контент

- Товары: `lib/products.ts`
- Категории: `lib/types.ts` (`CATEGORY_LABELS`)
- Контакты / футер: `components/Footer.tsx`
- О мастерской: `app/about/page.tsx`
- Стоимость доставки: константа `SHIPPING` в `app/cart/page.tsx` и
  `app/checkout/page.tsx`
